# ⚙️ Processos, Code Review e Ferramentas

## 1. Comunicação Assertiva (Método ASTUTO)
Ao documentar código, criar *Pull Requests* ou relatar incidentes técnicos, pondere o perfil de quem vai ler, utilizando a análise ASTUTO:
- **A**prender: O que precisam de aprender?
- **S**eu interesse: Qual é o interesse deles no tema?
- **T**ecnologia: Qual o nível de sofisticação técnica?
- **U**so de detalhes: Qual a profundidade necessária?
- **T**itularidade: Quem será o dono desta informação?
- **O**uvir: Como motivá-los a prestar atenção?

## 2. Integração com Inteligência Artificial
- **Senso Crítico Sem Terceirização:** Utilize assistentes de IA (Cursor, Gemini) para otimizar algoritmos, acelerar tarefas repetitivas e analisar refatorações. Contudo, **nunca terceirize o pensamento arquitetural**. Avalie e valide todas as linhas de código geradas antes da implementação.

## 3. Gestão de Mudança
- **Branches Limpas:** Isole novas funcionalidades e *bugfixes* em branches dedicadas.
- **Ambiente de Code Review:** O Code Review é uma ferramenta colaborativa de aprendizagem e partilha técnica. Mantenha as discussões focadas na solução, sem espaço para ego.
